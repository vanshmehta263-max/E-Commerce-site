NOVA E-COMMERCE FRONTEND
=======================

FILES
- index.html       Main website
- css/style.css    All styling and responsive layout
- js/script.js     Product data and interactive features

RUN
1. Extract nova_store.zip.
2. Open the nova_store folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Keep the css and js folders in the same structure. The HTML links to them using:
   css/style.css
   js/script.js

FEATURES
- Responsive desktop, tablet and mobile layout
- 28 products across Fashion, Tech, Home and Accessories; category filters, search and sorting
- Product quick-view modal
- Add to bag, quantity controls and remove item
- Wishlist
- Cart and wishlist saved in browser localStorage
- Newsletter demo form
- Demo checkout interaction

IMPORTANT
This is a front-end demo. Checkout does not take payments and there is no real account,
inventory, order management, admin panel or server database yet. For a real store,
connect a secure backend, database, authentication and a payment gateway.
Product photos are loaded from Unsplash, so internet access is needed for those images.
